# Language Modeling from First Principles — a Predictive-Text Engine

My work for the Learn Fast / askThili drill: an n-gram language model built from word counts (pure Python) —
counting n-grams, maximum-likelihood probabilities, text generation, add-k smoothing, and perplexity on held-out
text — wrapped into a reusable `NgramLM`.
